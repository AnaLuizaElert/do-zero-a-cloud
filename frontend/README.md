# Frontend

Interface React do workshop. O roteiro completo está no [README principal](../README.md).

## Executar com a API local

```bash
npm install
npm run dev
```

O padrão é `http://localhost:8090`.

## Executar apontando para uma API publicada

```bash
VITE_API_URL=https://SEU-BACKEND.up.railway.app npm run dev
```

Informe somente a origem, sem `/api/v1`.

## Build

```bash
npm run build
```
